架构只有三层

Workflow Studio（上层）定义 DAG、Prompt、Agent、验收策略、人工 Gate 和业务补救。
→
Workflow Runtime（Multica 底层）Run / Node / Attempt、CAS、Fence、Verification、Retry、Event + Outbox。
→
Task / Runtime（原能力复用）排队、机器分发、执行、心跳与恢复；不裁决业务成功。

为什么稳定

一致性：run lock + node revision CAS。

防旧结果：active attempt + 单调 fence。

不丢事件：状态、Event、Outbox 同一事务。

只有一个重试者：Workflow task 的 max_attempts=1，重试由 Runtime 负责。
